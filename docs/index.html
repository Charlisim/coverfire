After action

Three shots.
One sticky comment.

01 / COMMENT

Upsert, don’t spam

One PR comment marked <!-- coverfire -->. New pushes rewrite it in place. Project, patch, delta, uncovered hunks.

02 / CHECKS

Make merge earn it

coverage/project, coverage/patch, coverage/change. Check runs first; commit statuses if the token can’t. Wire them into branch protection.

03 / LINES

Point at the miss

Notice-level annotations on uncovered ranges in the diff. They don’t fail the job. The patch check does.

Local and CI

Run it where the tests already ran.

Not a GitHub App. GITHUB_TOKEN is enough. GitLab, Circle, Jenkins: same binary, same exit code. Comment on a GitHub PR from anywhere with --repo --pr --sha.

$ npx jest --coverage --coverageReporters=lcov
$ npx coverfire --min 80 --patch-min 80 --base origin/main
